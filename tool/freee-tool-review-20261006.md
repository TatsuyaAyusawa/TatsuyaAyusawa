### freee-tool.py（第1版で修正・12件）

1. **FreeeAPI.download（証憑の取得）が None を返して TypeError になる**
   429 を3回待った直後に 401（鍵の失効）が来ると、鍵を取り直したあとの再送で for が尽き、関数が暗黙に None を返していた。429 の回数と 401 の再送を分け、取り直した鍵で必ずもう1回送る。

2. **ダッシュボードで③「まだ処理していない証憑」が理由なく「?」になる**（2本のレビューが独立に検出）
   通帳待ちの集計の except 節で変数違いで `box_left` を None にしていた。`tsucho_wait` だけ「?」に。

3. **shiwake.csv を Excel で開いたままだと、プライベート回答のある行を含む登録が全部止まる**
   書き戻し失敗は FreeeError で来るのに `except OSError` で受けていた。`except (OSError, FreeeError)` に。

4. **口座の取引まとめ削除の完了時に、別の画面の本文（入力中の振替伝票など）を塗りつぶす**
   `M_wdel` に他画面と同じ `CUR` の見張りを入れ、`wdRun` 末尾は画面・事業所が変わっていなければ描き直す。失敗一覧は `WD.msg` に持たせて描画側で出す。

5. **証憑まとめ記帳「🔗 紐づけ」が、別の取引に付いた2ページ目も付けてしまう（二重添付）**
   登録側にある `page_conflict` の砦を `kicho_attach` にも入れ、候補からも外してボタン自体を出さない。

6. **証憑チェック「了解」1件が、科目を直した控え（元に戻す用）を消す**
   `_shohyo_record` が記録を丸ごと置換していた。prev なしの記録で上書きするときは prev・new・backup を引き継ぐ。回帰検査を追加。

### freee-tool.py（第2版で修正・5件）

13. **総勘定元帳「科目を変える」で、手で選んだ軽減8%・非課税の行まで新科目の既定税区分に書き換わる（仕入税額控除が過大）**
    「税区分も既定に合わせる」は、元の科目の既定のままだった行（何も手を入れていない行）だけに効かせる。新旧の科目の既定が同じ（消耗品費→会議費＝どちらも課税仕入10%）なら手で選んだ税区分と消費税額を保つ。既定が違う科目へ移すとき（費用→事業主貸＝対象外など）は従来どおり全行を新しい既定に合わせる。結果の画面に「保った行数」を出す。回帰検査を追加。

14. **ダッシュボードの単一事業所「未処理の明細」が消込中（status 4）を数えず、全事業所表の「残り」と食い違う**
    全事業所表と同じく 消込待ち(1)・消込中(4) を残りに数える。ラベルに「消込中を含む」と明記。消込中（一部だけ取引登録した明細）の残額処理は freee の自動で経理で行う。

15. **残高点検で `update_date`（口座設定の更新日）を同期日時と取り違え、連携していない口座も比較していた**
    口座一覧を `with_last_synced_at=true` で取り、`last_synced_at`（同期成功の日時）がある口座だけ比較・表示する。古い応答で項目が無いときだけ従来どおり（連携サービスの無い口座＝bank_id が null は除く）。

16. **証憑まとめ記帳「参考資料・控除・身分証明書」の保存が、全モジュール共通の控えの錠を握ったまま原本を全ページ取得していた**
    PDF 数ページで他タブの応答が数十秒止まっていた。関数全体の `@_sidecar` を外し、filed.json の読み→足す→書くだけを錠の中に。呼び手は従来どおり kicho の錠の中なので直列化は変わらない。

17. **Google Drive 未起動で起動すると共有ドライブの場所が既定 G: に固定され、「↻ 更新」でも直らない**
    `_drive_refresh` を追加。共有ドライブの記録・顧問先フォルダ・共通ルールを触る前に、場所が見えなければ ap_config に引き直させ、実在する場所が見つかれば ap_config と自分の定数を揃える。selftest の一時フォルダは触らない。

## 税務ロジックの前提確認

回答反映（AP_ANSDEAL）の会議費／交際費の判定基準「1人あたり1万円以下」は、措法61条の4第6項（令和6年4月1日以後支出分から5,000円→10,000円）に合致。交際費等の損金不算入制度の適用期限は令和9年3月31日までに開始する事業年度まで延長済み。
出典: [国税庁 法人税のあらまし（交際費等）](https://www.nta.go.jp/publication/pamph/hojin/aramashi2025/pdf/02-16.pdf)、[山田＆パートナーズ 令和6年度改正解説](https://www.yamada-partners.jp/reform/r6/h05-extension-and-payment-of-entertainment-expense-non-deductible-system)
なお個人事業主には交際費の損金算入限度は無いため、この区分は所得税額には影響しない（科目の整理としてのみ機能）。

修正13の消費税の扱い: 手で選んだ税区分を保つのは「新旧の科目の既定税区分が同じ」場合に限る。課税→対象外（事業主貸等）のように科目の性質が変わる振替は全行を新しい既定に合わせるため、課税仕入の取り残しは起きない。
