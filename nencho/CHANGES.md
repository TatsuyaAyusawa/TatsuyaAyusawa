# 旧版 → 改訂版 変更点（令和8年分 年末調整の質問用紙）

旧版（2026-10-05生成・6ページ）を、令和8年分の申告書4様式の記載事項・令和8年度税制改正・平文UX・チェック形式・番号法の観点で監査し、全面改訂した。設問番号は Q1〜Q18 → Q1〜Q20（地震保険・専従者の設問を追加、住宅ローンを5ページへ移動）。

## 1. チェック形式（依頼事項）

| 旧版 | 改訂版 |
|---|---|
| 全て同じ「□」。1つ選ぶのか複数か設問ごとに不明（明記は2か所のみ） | **○＝どれか1つに✓、□＝当てはまるもの全部に✓** に統一。1ページ「書き方」に凡例（記入見本付き）、各設問の右端にバッジ「どれか1つに✓」「当てはまるもの全部に✓」 |
| 「ない」と内訳が同じ□で混在（Q7・Q11・Q16・Q17・家族の収入・配偶者の収入） | 「○ない ○ある → □内訳」のゲート構造に統一 |
| 「→」が分岐・記入欄・箇条書きの3用途で混在 | 設問ジャンプは「▶ Aへ」、条件付き記入欄のみ「→」 |
| 金額欄の直後に次の□が来て帰属が不明 | 項目間隔を広げ、□を10.4pt・○を直径10.4ptに拡大 |

## 2. 申告書カバレッジ（全問答えれば申告書が埋まるか）

追加した設問・欄（旧版では申告書の欄が埋まらなかったもの）:

- **非居住者の親族**（扶養控除等申告書B欄「非居住者である親族」「生計を一にする事実」）: 住所欄・送金額（今年の合計）・「外国に留学中」・30〜69歳の要件（留学／障害／38万円以上送金）の案内 → 2ページA欄・3ページ各人
- **別居親族の生計一判定**: 「別・施設・外国の方：生活費を ○出している（年 約＿万円） ○出していない」
- **他の所得者が控除を受ける扶養親族（D欄）**: Q10 に「扶養に入れている人（配偶者／ほかの方：氏名・続柄・住所）」
- **事業専従者の除外**: 配偶者（A欄）に加え、家族についても Q11 を新設
- **退職手当等を有する配偶者・扶養親族（住民税欄）**: 配偶者・家族の収入に「□退職金」を明示
- **障害者欄**: 手帳の種類・等級の記入指示、手帳コピーの提出、市区町村の「障害者控除対象者認定書」、特別障害者判定の例示
- **勤労学生**: 学校種別（高校／大学等／専門学校等）・入学年月・卒業予定（令和9年分用）・証明書が要るのは専修学校等のみと明示
- **異動月日**: 名字変更（月・理由）、結婚・離婚・死亡（月日）、家族の死亡（月）
- **本人の所得見積（基礎控除申告書）**: Q6 を細分化（年金＝遺族・障害年金除外、保険会社の個人年金・満期金、退職金＋勤続年数、株＝特定口座源泉あり・NISA除外、事業・副業＝売上・経費・青色申告の有無、不動産、その他）
- **配偶者の所得見積**: 同じ区分で細分化、1〜11月明細＋12月見込みの案内、130万〜210万円帯は正確に
- **地震保険**（Q14 新設）: 保険会社・居住者（本人／家族／貸家）
- **社会保険料**（Q15）: だれの分・種類（国保／後期／介護／任意継続）・払い方（納付書か年金天引きか）・1〜12月の額
- **生命保険**（Q13）: 種類（生命・医療／個人年金）、受取人の調べ方、契約者が家族の場合の扱い
- **住宅ローン**（Q16）: 居住開始年（令和4年以前／5年以後）、12月31日居住、ローン本数・借換え、連帯債務、年末残高の印字有無（調書方式）、1年目は確定申告
- **前職**（Q17）: 会社名・退職日、扶養控除等申告書の提出有無（甲欄／乙欄）、源泉徴収票の有無と届かない場合の案内
- **住民票の住所**（Q3）、**氏名欄と通称名**（Q1）、**西暦の生年月日**（全員）
- **家族ゼロの明示**: 3ページ冒頭「★当てはまる方は ○いない ▶4ページへ ○いる」
- **年末調整でできないもの**（医療費控除・ふるさと納税・住宅ローン1年目・雑損）の案内 → 4ページ下部（改訂版では5ページ側の案内に統合）

## 3. 令和8年分の数値・制度（Web確認済み）

- 配偶者のマイナンバー省略基準: 「給料210万円超」→ **給料だけで207万円超**（配偶者特別控除の上限＝合計所得133万円）

- 23歳未満の扶養親族がいる場合の生命保険料控除の特例（令和8年分、一般・新契約の上限4万→6万円）の案内を Q13 に追加（判定情報は3ページの家族欄で取得）
- 年齢基準: 22歳以下＝平成16年1月2日以後生まれ、16歳未満＝平成23年1月2日以後生まれ

- 様式名: 「令和9年分 給与所得者の扶養控除等**（異動）**申告書」、基礎控除申告書等の正式名称、住宅借入金等特別控除申告書を署名欄の列挙に追加

## 4. 平文UX

- 全設問に「分からなければ空欄で結構です」方針＋★必須項目（Q1・Q3・Q9・署名）を明示
- 専門用語に言い換えを併記（世帯主・額面・青色事業専従者給与→「家族の商売の手伝いの給料」・源泉徴収票・任意継続・後期高齢者医療・調書方式 など）
- 乙欄の方の記入範囲は、従業員の記憶に頼らず**勤め先が1ページ目で指定**（「書いてもらう範囲 ○全部 ○一部だけ」）。Q5 は「メインの勤め先はどちらか」に簡略化
- はがき未着・紛失・電子交付の行き先、源泉徴収票が届かない場合、番号が分からない場合、家族4人以上の場合（勤め先からもう1枚）など「止まりやすい場面」に行動指示
- 出し方（紙／写真）・両面印刷（1〜5ページ）・6ページは別紙片面、を勤め先欄に明記

## 5. 番号法・個人情報

- 6ページ: 利用目的の明示、収集範囲（だれの番号を書くか）、「前に出した」で省略できる条件（年末調整書類で提出済み＝給与支払者の帳簿）、本人確認欄（番号確認＋身元確認の正しい組合せ、「前に出した」場合は帳簿照合）、保管・廃棄、LINE・メール送信不可、別紙として分離保管
- 障害者手帳（要配慮個人情報）の取得目的と任意性の説明、署名欄に同意文言
- 署名欄: 申告書は従業員本人が提出するものであること（税理士事務所は代書）を明記した「確認と同意」3項目
- 記入例の架空番号は検査数字不一致の並び（1111…／9999…）とし「架空です」を明記

## 8. 改訂版の再監査（6レンズ・85件）を反映した最終調整

- **チェック形式の残り**: はがきの状況（Q12）・社会保険の種類（Q15）・生命保険の種類（Q13）・卒業予定（Q8）など、同時に成り立つ選択肢を□（全部）に、排他を○に再分類。留学中の□は「住まい ○外国」の直後へ移動
- **6ページ（マイナンバー）**: 利用目的を①申告書②源泉徴収票③給与支払報告書＋「□社会保険の届出にも使う（勤め先が✓）」の順に整理。「前に出した」の条件を「去年もこの勤め先で年末調整をして番号を書いた方（勤め先が番号の帳簿を備えている場合）」に。対象外の方は「○対象外（お名前だけ）」で空欄と区別。配偶者の扶養に入る22歳以下の子は「会計事務所が判断」（生命保険料控除の特例用）。写真提出時の本人確認（カードの写真）と、勤め先欄の本人確認書類（通知カードは住所・氏名が同じ場合のみ／番号入り住民票／会計事務所が代わりに確認）・番号を出せない場合の記録・廃棄の案内
- **住宅ローン（Q16）**: 「去年までに確定申告をして受けている」「今年、家を買った・建てた（1年目）」に言い換え。単身赴任で家族が住んでいる場合の選択肢、連帯債務の相手の氏名・勤め先・負担割合、年末残高の印字有無による書類の案内（調書方式）
- **社会保険料（Q15）**: 本人の年金から天引きされる介護保険料等は控除できる旨を明記（家族の年金天引き分のみ不可）
- **税務の数値**: 5万円きざみで控除が変わる帯を「170万〜207万円（配偶者）」「150万〜200万円（19〜22歳）」に修正。23歳未満の特例は「収入136万円以下・新契約で年6万円超」と条件を明記。国民年金基金の証明書は基金から届く旨を追記。「メイン」の勤め先＝扶養控除等申告書を出した先と定義
- **記入例**: 新入社員の設定に合わせ全員の番号を記入（検査数字不一致の架空番号）、さくらを西暦記入の見本に、Q20・社会保険届出✓の見本を追加
- **平文**: 「会計事務所」に用語統一（鮎澤パートナーズを冒頭で明示）、Q3の「引っ越した」の二重記入防止、Q10の言い換え（健康保険の扶養と区別）、Q6の理由付け、勤労学生控除の証明書の説明、フリガナ・ローマ字サイン・在留カードの案内
- **レイアウト**: ○□を拡大（直径11.2pt／11.2pt角）、マイナンバーのマスを16pt角に、灰色の勤め先欄は2パス生成で文字の下に塗る、Q番号・数字＋単位を行またぎしない、Q20の続き・メモ欄（4ページ下部）を追加、綴じ側余白を確保
