# 令和8年分 年末調整の質問用紙（従業員記入用）

顧問先の従業員に配る「年末調整の質問用紙」と、その記入例を生成するスクリプトです。
従業員がこの用紙を全部埋めれば、会計事務所が次の申告書を作成できる設計になっています。

- 令和8年分 給与所得者の扶養控除等（異動）申告書
- 令和8年分 給与所得者の基礎控除申告書 兼 給与所得者の配偶者控除等申告書 兼 給与所得者の特定親族特別控除申告書 兼 所得金額調整控除申告書
- 令和8年分 給与所得者の保険料控除申告書
- 令和8年分 給与所得者の（特定増改築等）住宅借入金等特別控除申告書（2年目以降。税務署送付用紙の空欄補完）
- 令和9年分 給与所得者の扶養控除等（異動）申告書

## 生成されるファイル（`output/`）

| ファイル | 内容 |
|---|---|
| `令和8年分_年末調整の質問用紙.pdf` | 空欄版（6ページ） |
| `令和8年分_年末調整の質問用紙_1-5ページ.pdf` | 空欄版のうち質問ページだけ（両面印刷用） |
| `令和8年分_年末調整の質問用紙_マイナンバー別紙.pdf` | 6ページ目だけ（別の紙に片面印刷し、他ページと分けて保管） |
| `令和8年分_年末調整の質問用紙（記入例）.pdf` | 記入例（架空の山田太郎一家。赤字＝従業員、青字＝勤め先） |

## 使い方

```bash
pip install reportlab pypdf
python3 nencho_form.py --out-dir output            # 空欄版＋記入例
python3 nencho_form.py --out-dir output --blank    # 空欄版のみ
python3 nencho_form.py --out-dir output --sample   # 記入例のみ
```

フォントは BIZ UDPゴシック（SIL Open Font License）を使います。`fonts/` に無ければ
Google Fonts の GitHub リポジトリから自動取得します（取得できない環境では IPA Pゴシックで代用）。

## 用紙の設計ルール

- **○ ＝ どれか1つだけに✓、□ ＝ 当てはまるもの全部に✓**。1ページ目「書き方」に凡例、各設問の右端にバッジ（どれか1つに✓／当てはまるもの全部に✓）。
- 「○ない ○ある → □内訳」のゲート構造で、該当しない人は1つ✓するだけで次へ進める（空欄と「該当なし」を区別）。
- 設問ジャンプは「▶ Aへ」「▶ 5ページへ」、条件付き記入欄は「→ 前の名字 ___」。
- ★印は必須項目（Q1・Q3・Q9・署名）。それ以外は「分からなければ空欄で結構です（会計事務所からお尋ねします）」。
- マイナンバーは6ページ目（別紙）だけ。利用目的・収集範囲（番号法）・本人確認欄・保管廃棄の案内付き。LINE送信不可。
- 令和8年分の改正（基礎控除・給与所得控除の最低保障74万円・扶養親族等の所得要件62万円＝給与136万円・特定親族特別控除＝給与136万円超197万円以下・配偶者特別控除＝給与207万円以下・23歳未満扶養親族がいる場合の生命保険料控除特例）を前提にしきい値と案内文を設定。

`YEAR` / `NEXT_YEAR` と、本文中の年齢基準日（平成16年1月2日・平成23年1月2日）、しきい値（136万・197万・207万・200万）、様式名を翌年分に合わせて更新してください。
